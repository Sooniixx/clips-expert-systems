# Експертні системи на базі CLIPS

Репозиторій містить результати розробки роботи у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Автор
- **Студент:** Фесенко Софія Олегівна
- **Група:** ІН-32/1
- **Варіант:** 7

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts, deffacts);
- `Lab2/` – створення шаблонів (deftemplate), впорядкованих фактів та семантичних мереж (AKO, IS-A);
- `Lab3/` – формування бази правил (defrule) та діагностика дефіциту поживних речовин рослин;
- `Lab4/` – створення та використання процедурних функцій (deffunction);
- `Lab5/` – дерева рішень, префіксні вирази та логічне виведення (інтерактивне опитування);
- `README.md` – опис проєкту та висновки.

## Висновки
Під час виконання лабораторних робіт було опановано роботу з системою контролю версій Git та сервісом GitHub. Сформовано навички структурування навчальних проєктів, створення репозиторіїв, завантаження вихідного коду експертних систем CLIPS та оформлення документації мовою розмітки Markdown у файлі README.md. Усі створені бази знань, шаблони та правила з попередніх робіт успішно систематизовано за відповідними директоріями.
